# Maintainer and agent files

This directory is intentionally small. It contains material that helps agents
and maintainers work on the repository but does not belong in the user manual.

- [`skills/`](skills/) — installable Agent Skills.
- [`architecture/README.md`](architecture/README.md) — current durable
  architecture boundaries.
- [`plans/`](plans/) — accepted future designs that still affect current work.
- [`runbooks/`](runbooks/) — release, signing, and packaging procedures.

User-facing installation, desktop usage, configuration, rules, and CLI
documentation lives in [`docs/`](../docs/README.md). Active tasks live in
[`TODO.md`](../TODO.md). Temporary investigations, completed migration diaries,
and one-off validation output should stay in issues, pull requests, or local
working notes rather than accumulating here.
